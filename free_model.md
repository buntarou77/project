# free_model — журнал исполнения

## 19.11.2026 — Этап Y

Выполнено: Y1 (ночные смены), Y2 (полные окна многодневной аренды), Y3
(референсы клиента), Y4 (P3: команда без активных специалистов), Y5
(notify timeout/reclaim/cleanup), R2 (Stats NaN), R10/R12 (уборка), тесты и
документация.

Расхождения инструкции с кодом:
- `windowDurationMin(open, close)` при `open === close` возвращает 0, чтобы zod
  отклонял такое окно (формула из документа дала бы 1440).
- В `Requests.tsx` поле «Часов» скрывается при `form.days <= 1`, а не при
  `service.multiDayMax > 1` — иначе однодневная бронь multi-day-услуги теряет
  выбор часов.
- Найден и исправлен баг ночной доступности: для слота после полуночи
  `specialistWindowOk` не учитывал ночное окно предыдущего дня, из-за чего
  ночная смена специалиста обрывалась в 00:00. Добавлен тест на смену 22:00–06:00
  с окном специалиста через полночь.
- `server/tests/regressions.test.ts` содержит 2 теста (reclaim + cleanup), а не 6:
  остальные 4 integration-сценария добавлены в `api.test.ts`; суммарно 42.
- Для последовательного embedded PG в `server/vitest.config.ts` включён
  `fileParallelism: false`, а `api.test.ts` после остановки PG удаляет
  автоматический `TEST_DATABASE_URL`.

Проверки 19.11.2026: typecheck (корень + server), 64/64 unit, 42/42
integration, build, e2e 18/18, smoke 9/9, sync-shared.

Вне прогона: A2, A4, A5, A7, A8, R9, R11, вариант В R8.
